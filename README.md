# 🌊 Dashboard ติดตามระดับน้ำในคลอง น้ำท่วมถนน และกล้องวงจรปิด CCTV
### พื้นที่: กรุงเทพมหานคร • นนทบุรี • ปทุมธานี (เน้นพิเศษ: งามวงศ์วาน, ประชาชื่น, แจ้งวัฒนะ, ม.เกษตรศาสตร์)

เว็บแอปพลิเคชัน Dashboard แบบ Interactive สำหรับติดตามสถานการณ์น้ำท่วม ระดับน้ำในคลอง ระดับน้ำบนผิวจราจร และภาพวิดีโอกล้องวงจรปิด CCTV แบบเรียลไทม์

---

## 🌟 ฟีเจอร์หลัก (Features)

1. **🚨 ปักหมุด 5 โซนเฝ้าระวังพิเศษไว้ด้านบนสุด (Top Pinned Priority Zones)**:
   - **โซนงามวงศ์วาน**: สี่แยกพงษ์เพชร, หน้าเดอะมอลล์งามวงศ์วาน, ใต้ทางด่วน (ระดับน้ำ 25 ซม., คลองบางเขน 1.45 ม.รทก.)
   - **โซนประชาชื่น**: สี่แยกประชานุกูล, เลียบคลองประปา, ประชาชื่น 30 (ระดับน้ำ 15 ซม., คลองประปา 1.28 ม.รทก.)
   - **โซนแจ้งวัฒนะ**: หน้าศูนย์ราชการฯ, วงเวียนหลักสี่, หน้าเซ็นทรัล (ระดับน้ำ 30 ซม. วิกฤต, คลองบางตลาด 1.68 ม.รทก.)
   - **โซน ม.เกษตรศาสตร์**: แยกเกษตร, ประตู 1-3 งามวงศ์วาน, พหลโยธิน (ระดับน้ำ 18 ซม., คลองบางเขน/บางบัว)
   - **โซน อ.เมือง นนทบุรี**: สี่แยกแคราย, ถ.รัตนาธิเบศร์, ท่าน้ำนนท์, สะพานพระนั่งเกล้า (ระดับน้ำ 16 ซม., แม่น้ำเจ้าพระยา/คลองบางใหญ่ 1.58 ม.รทก.)
   - แต่ละโซนมีการ์ดแสดงระดับน้ำถนน, ระดับน้ำคลอง, ปริมาณฝนสะสม (มม.), สถานะฝนตก (กำลังตก/หยุดแล้ว), ระยะเวลาที่ตก, เวลาหยุดตก, คำแนะนำการเดินทาง และ**ภาพกล้องวงจรปิด CCTV สดพร้อมเวลา OSD**

2. **🌧️ ข้อมูลปริมาณฝนสะสม และสถานะฝนตกแบบเรียลไทม์ (Rainfall & Storm Tracking)**:
   - ปริมาณฝนสะสม 24 ชั่วโมง (มม.)
   - ระบุชัดเจนว่า **ฝนกำลังตกอยู่หรือไม่** (เช่น ฝนตกหนักต่อเนื่อง, ฝนปานกลาง, ฝนปรอยๆ, หรือฝนหยุดตกแล้ว)
   - ระบุว่า **ตกมานานเท่าไหร่** (เช่น ตกมาแล้ว 2 ชม. 50 นาที โดยระบุเวลาเริ่มตก เช่น 05:10 น.)
   - ระบุว่า **หยุดตกเวลาเท่าไหร่** (กรณีฝนหยุดแล้ว เช่น หยุดตกเมื่อเวลา 07:40 น. พร้อมระยะเวลารวมที่ตกไป)
   - แสดงข้อมูลเรดาร์คาดการณ์การเคลื่อนตัวของกลุ่มฝน

3. **🛶 ระดับน้ำในคลองสายสำคัญ (Canal Water Levels)**:
   - คลองเปรมประชากร, คลองบางเขน, คลองประปา, คลองบางตลาด, คลองบางบัว, คลองรังสิตประยูรศักดิ์, คลองลาดพร้าว, คลองแสนแสบ, คลองบางใหญ่, คลองเชียงราก
   - แสดงระดับน้ำ (ม.รทก.), ระดับเตือนภัย, ระดับวิกฤต, อัตราความจุคลอง (%), อัตราการไหล และการเดินเครื่องสูบน้ำ
   - เกจวัดระดับสี: เขียว (ปกติ), น้ำเงิน (เฝ้าระวัง), ส้ม (เตือนภัย), แดง (วิกฤตล้นตลิ่ง)

3. **🛣️ ระดับน้ำท่วมตามถนนต่างๆ (Road Water Levels)**:
   - ความสูงน้ำท่วมขัง (ซม.), ช่องจราจรที่ได้รับผลกระทบ
   - คำแนะนำสำหรับยานพาหนะ (รถเล็กผ่านได้ / ควรหลีกเลี่ยง / รถทุกชนิดห้ามผ่าน)
   - สาเหตุและสถานะการทำงานของเครื่องสูบน้ำ

4. **📹 กล้องวงจรปิด CCTV และสตรีมภาพถนน (Live CCTV Feeds)**:
   - สตรีมภาพเคลื่อนไหวจำลองสภาพการจราจรจริง พร้อมสภาพฝน คลื่นน้ำท่วมขังบนผิวถนน แสงไฟหน้ารถ และละอองน้ำ
   - ประทับเวลาสด (Live OSD Clock) แบบวินาทีต่อวินาที
   - ปุ่ม **⛶ ขยายดูสด / ขยายเต็มจอ** ในรูปแบบ Modal คมชัดระดับ HD

5. **⏱️ เวลาดึงข้อมูล และปุ่มกด Refresh (Data Retrieval Timestamp & Refresh)**:
   - แสดงเวลาที่ดึงข้อมูลล่าสุดในรูปแบบไทยชัดเจน (เช่น `27 ก.ย. 2569, 07:55:00 น.`)
   - ปุ่ม **"🔄 รีเฟรชข้อมูล (Refresh)"** เมื่อกดแล้วจะแสดงแอนิเมชันกำลังหมุน ดึงข้อมูลและอัปเดตระดับน้ำและเวลาทันที
   - ตัวเลือกรีเฟรชอัตโนมัติ (Auto-refresh) ทุก 15 วิ, 30 วิ, 1 นาที หรือปิด

6. **📈 กราฟแนวโน้มระดับน้ำในคลอง (Chart.js 24-Hour Historical Trend)**:
   - กราฟเส้นแบบเต็มความกว้าง (Full Width) เปรียบเทียบระดับน้ำในคลองย้อนหลัง 24 ชั่วโมง
   - แสดงจุดวิกฤตและแนวโน้มการขึ้น-ลงของน้ำในจุดสำคัญ (งามวงศ์วาน, พงษ์เพชร, แจ้งวัฒนะ, ประชาชื่น, รังสิต)
   - ไม่โหลดไลบรารีแผนที่ภายนอก ช่วยให้หน้าเว็บโหลดได้รวดเร็วทันใจ ไร้ภาระค่า Token ใดๆ

7. **🌐 การเตือนภัยและพยากรณ์น้ำท่วมล่วงหน้า 7 วัน โดย Google Flood Hub (AI Flood Forecasting)**:
   - ผสานโมเดลปัญญาประดิษฐ์ (AI Hydrological Simulation) จาก Google Flood Hub คาดการณ์ระดับน้ำล่วงหน้าสูงสุด 7 วัน
   - ติดตามระดับความเสี่ยงลุ่มน้ำเจ้าพระยาตอนล่าง (สถานี อ.เมือง นนทบุรี / ท่าน้ำนนท์, คลองรังสิต ปทุมธานี, คลองเปรมประชากร/บางเขน งามวงศ์วาน, และคลองบางตลาด แจ้งวัฒนะ)
   - แสดงระดับความน่าจะเป็นในการเกิดน้ำท่วม (Risk Probability Gauge %), วันที่คาดการณ์ระดับน้ำสูงสุด (Peak Forecast Date), และคำแนะนำการเตรียมพร้อม
   - แสดงป้ายแจ้งเตือน AI สอดคล้องใน 5 โซนปักหมุดหลัก
   - ปุ่มเชื่อมโยงเปิดดูแผนที่คาดการณ์สดบนเว็บไซต์ทางการของ [Google Flood Hub](https://floodhub.world/)

8. **🔍 ระบบค้นหาและตัวกรอง (Search & Filter)**:
   - กรองตามจังหวัด: กรุงเทพมหานคร, นนทบุรี, ปทุมธานี
   - กรองตามระดับความรุนแรง: วิกฤต, ปานกลาง, ปกติ
   - ค้นหาด้วยคีย์เวิร์ด (เช่น "งามวงศ์วาน", "พงษ์เพชร", "แจ้งวัฒนะ")

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: รันผ่าน Python Server (แนะนำ)
เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
python3 server.py
```
จากนั้นเปิดเบราว์เซอร์แล้วเข้าไปที่:
👉 **http://localhost:8080**

(หรือหากต้องการให้เปิดเบราว์เซอร์อัตโนมัติ ให้ใช้ `python3 server.py --open`)

### วิธีที่ 2: ดับเบิลคลิกเปิดไฟล์ `index.html` โดยตรง
สามารถดับเบิลคลิกที่ไฟล์ [index.html](file:///Users/wisutthinun/Downloads/คลี่คลายน้ำท่วม/index.html) ใน Finder เพื่อเปิดดูบน Google Chrome, Safari, หรือ Edge ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

## 📁 โครงสร้างไฟล์
- `index.html` : โครงสร้างหน้าเว็บหลักของระบบ Dashboard
- `style.css` : สไตล์การออกแบบธีมศูนย์บัญชาการ (Command Center) และ Glassmorphism
- `data.js` : ชุดข้อมูลสถานีวัดน้ำคลอง จุดน้ำท่วมถนน และกล้อง CCTV (กทม. นนทบุรี ปทุมธานี)
- `app.js` : ลอจิกการทำงาน ปุ่มรีเฟรช ตัวจับเวลา กราฟแนวโน้ม และการเชื่อมโยงข้อมูลกล้อง CCTV สด
- `server.py` : สคริปต์ HTTP Server น้ำหนักเบา
